Welcome to the Rampart Webserver

Your server is running, and can now be customized.

See the web_server/web_server_conf.js script in the Rampart distribution directory.

There are also some examples included to get you started.

  • Show my request
  • Show my request (with highlighting)
  • A simple websockets chat app

There are a few more in the web_server/apps/test-modules/ directory.

Mini IDE

The Mini IDE is a browser-based editor, file browser and terminal for the files in the web_server/ directory, with an interactive rampart session and the searchable Rampart documentation. It serves this same site, so scripts written in it work the same with or without the IDE.

To start it, run from the web_server/ directory:

    ./start-mini-ide.sh

The first start asks for a password, whether to listen on all network interfaces, and which port to use (default 8089). Then open:

    http://localhost:8089/ide/

using the port you chose. Stop it with ./start-mini-ide.sh stop. Anyone who logs in can run commands as the user running the server, so only listen on all interfaces on a trusted network.

Everything the IDE needs, including its copy of the documentation, is kept in web_server/ide/, apart from your site's html/, apps/, wsapps/ and data/. To turn this directory into a web server you can redistribute without the IDE, stop the IDE and delete it:

    rm -rf ide mini-ide-conf.js start-mini-ide.sh AGENTS.md CLAUDE.md

AGENTS.md and CLAUDE.md are notes for coding agents, written each time the IDE starts. The site then runs as usual with rampart web_server_conf.js start.

Authentication

To enable authentication, set authMod: true in web_server_conf.js and run initial setup:

    rampart apps/auth.js

Once enabled:

  • Protected page — requires login (shows auth info)
  • Admin panel — user and session management (admin only)
  • Login page

See auth-conf.js for configuration. CLI admin: rampart apps/auth.js help
