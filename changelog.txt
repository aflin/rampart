v0.7.1
    -rampart and installer
                            Docker builds for all.  langtools gpu build
                            on arm.  Install fixes.  AlmaLinux 8, FreeBSD
                            and 32-bit Raspberry Pi build fixes.

    -rampart-sql            Fused keyword + vector search --
                            "doc LIKEP ? OR v LIKEV ?" -- with reciprocal
                            rank fusion, plus $krank and $vrank for the
                            per-side scores.
                            chunkembed() for chunked, multi-vector rows.
                            onnxEmbed and clipEmbed join llamaEmbed as
                            per-connection embedding backends; clipEmbed
                            enables text-to-image search.
                            Much faster faiss IVFPQ index builds, with
                            gpu assist where available.
                            rex: new Unicode character classes (\uword,
                            \ualpha, \udigit, \ualnum, \umark, \uspace,
                            \upunct) match whole utf-8 characters, with
                            repetition counted in characters.  The
                            default index word expression is now
                            '[\uword]{2,99}', so full-text indexes
                            tokenize every space-separated script
                            correctly by default (including ZWNJ word
                            breaks for e.g. Persian).
                            rex: new '\bound' zero-width word boundary,
                            for tokens that must not begin or end on
                            punctuation, e.g. '\bound[\alnum.\-]+\bound'
                            takes '4.10.3' out of "see section 4.10.3."
                            without the closing period.  A trailing
                            '\bound' shortens a repetition until the
                            boundary is met; the start and end of the
                            text count as boundaries.  ('\b' by itself
                            is still a backspace.)
                            Astral-plane characters in JS strings are
                            recombined from duktape's internal CESU-8 to
                            standard utf-8 when bound as sql parameters.

    -rampart-server         preThreadFunc.  sslKey/sslCert accept
                            in-memory PEM per listen block.  Reworked
                            startup to bind privileged ports before
                            dropping permissions, and to reset the home
                            directory afterwards.
                            macOS thread/fork fixes when using llamacpp.

    -rampart-langtools      New rampart-onnx and rampart-clip modules,
                            with internal chunking.  macOS x86 fixes;
                            a cuda version mismatch is now reported
                            rather than crashing.

    -rampart-vector         b8 ("bit") binary vectors, with hamming as
                            the default metric.

    -rampart-treesitter     extract() to retrieve the source text of a
                            named function.  tree-sitter array.h fix.

    -rampart-python         pip3r and python3r wrappers, installing to a
                            per-user module directory when the rampart
                            install is not writable.

    -rampart-date-holidays
                            Node-based update script.
