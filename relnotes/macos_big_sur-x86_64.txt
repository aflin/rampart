This is the macOS build for Intel Macs -- new in this release.

Optional packages
-----------------
  rampart --install --list      see what is available for this build
  rampart --install all         install everything

Local LLM / vector search / embeddings (rampart-langtools)
----------------------------------------------------------
`rampart --install all` installs it -- llamacpp, faiss, clip and
rampart-onnx.  There is one build; nothing else to choose.

These run on the CPU.  GPU acceleration is not available in the Intel
build -- llamacpp's Metal backend and rampart-onnx's GPU path are both
turned off here.  Expect model work to be slower than on an M-series
Mac.

rampart-graphicsmagick
----------------------
The image module links against a system GraphicsMagick, which is not
bundled:

  brew install graphicsmagick

(If Homebrew is not installed, see https://brew.sh.)  require('rampart-gm')
prints this command for you if the library is missing.
